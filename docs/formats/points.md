# Общ списък на точките: `static/points.json`

Публикува се в Pages: https://ilianrvd.github.io/nowcasting-public/static/points.json

Единен списък на летищата (по-късно станции на НТУ, SYNOP и участъци от пътя). Всички проекти ползват едни и същи идентификатори. Формат, съгласуван с fogNowcast (`docs/points.md`).

Личен проект, не е официален продукт на сертифициран доставчик. Контакт: Илиан Манафов, ilianm@mail.bg.

## Идентификатори

| Тип (`type`) | Формат | Пример |
|---|---|---|
| `airport` | ICAO | `LBSF` |
| `ntu` | `NTU:<station_id>` | `NTU:57` |
| `synop` | `SYNOP:<WMO>` | `SYNOP:15614` |
| `segment` | `SEG:<ref>-<номер>` | `SEG:A1-012` |

Веднъж даден, идентификаторът не се сменя. Отпаднала точка остава с `"active": false`.

## Структура

| Поле | Описание |
|---|---|
| `generated_at` | ISO 8601 UTC. Файлът е статичен: времето е на последната промяна на съдържанието. |
| `source` | Откъде са данните. |
| `version` | Цяло число; расте при всяка промяна на списъка. |
| `points[].id`, `type`, `name`, `name_en` | Виж таблицата по-горе. |
| `points[].lat`, `lon` | WGS84, градуси. |
| `points[].elev_m` | Надморска височина в метри или `null`. |
| `points[].active` | `true` по подразбиране. |

## Текущо състояние (версия 1)

Само петте летища, с координати и височини от AIP, сверени на 2026-11-25: LBSF, LBBG, LBWN, LBPD, LBGO.

Вътрешно (`config/settings.py`, `config/sites.csv`) координатите на LBSF са приведени към AIP. Останалите четири летища вътре са на ≤ 16 m от AIP и не са променяни.
