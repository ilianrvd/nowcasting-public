## Честота и свежест

Файлът се сглобява на всеки пуск (~20 мин), но към Ogimet отива най-много една заявка на 50 мин. Между заявките (и при неуспех) се публикуват кешираните съобщения с оригиналните им `time`. Файлът не е празен при липса на нови данни; не се пише само ако няма и кеш.

- `generated_at`: кога е сглобен файлът.
- `fetched_at`: кога последно е успяло изтеглянето от Ogimet.
- Възрастта на данните се гледа по `time` и `fetched_at`.

## Структура

```json
{
  "generated_at": "2026-11-25T18:20:03Z", "fetched_at": "2026-11-25T18:06:41Z", "source": "ogimet",
  "reports": [
    {"id": "SYNOP:15614", "time": "2026-11-25T18:00:00Z", "t": 0.5, "td": 0.5,
     "wind_kt": 0, "wind_dir": null, "vis_m": 1000, "ww": 45, "wx": ["FG"],
     "n_oktas": 8, "h": 9, "cloud_base_ft": null, "raw": "AAXX 25181 15614 …"}
  ]
}
```

| Поле | Описание |
|---|---|
| `id` | `SYNOP:<WMO>` (виж `static/points.json`). |
| `time` | Час на наблюдението (UTC). |
| `t`, `td` | °C, десети от градуса. `null`, ако липсват или са зададени като влажност. |
| `wind_kt`, `wind_dir` | В kt (m/s се превръща по индикатора на съобщението). `wind_dir` е `null` при щил, променлива посока (99) и нечетима. |
| `vis_m` | От кода VV (метри). Код 00 = 50, 99 = 50000 (границите на кодовете). |
| `ww` | Кодът на настоящото време (WMO 4677) или `null`. |
| `wx` | Текст по `ww`: мъгла (`BR`, `BCFG`, `MIFG`, `VCFG`, `FG`, `FZFG`), валеж, гръмотевици. Минали явления (20–29) и неописаните кодове → `[]`. |
| `n_oktas` | Облачност N в осми (0–8); `null` при „не е наблюдавана“ и „небето не се вижда“ (9). |
| `h` | Код на височината на най-ниския облак (WMO 1600, 0–9). |
| `cloud_base_ft` | Винаги `null`: SYNOP дава само клас на височината. Полето е за съвместимост с METAR. |
| `raw` | Съобщението (AAXX…), винаги се пази. |

Неразчетено или липсващо поле е `null`. Разчита се само секция 1; секциите 3 и 5 се игнорират.
